# Fix-Events website recreation

A responsive, static recreation of https://www.fix-events.fr/ using plain HTML, CSS and JavaScript: the homepage and 23 secondary pages. Reference photography, product images and logos are stored in `assets/`, alongside locally hosted Rubik and Lato fonts.

## Run locally

From `/workspace/CodexWeb`:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

No package installation is needed. The HTML pages are bundled: styles, scripts, fonts and optimized images are embedded so each page displays without sibling files. All internal menu links navigate to local pages.

Edit `page.html` for the homepage, `styles.css` for the shared design, and `script.js` for interactions. Secondary page copy, product specifications and prices are retained in `site-data.json`; their layouts are generated by `build-pages.py` using the homepage navigation and footer. Rebuild all HTML pages using the standard Python library:

```sh
python3 build-preview.py
```

This command also regenerates the secondary templates under `pages/`. Edit the data or generator rather than the generated HTML. `assets/preview/` and `assets/secondary/` contain retained optimized images. Builds make no network requests.

## Behavior and scope

- Responsive navigation with local service and equipment pages, telephone link and section anchors.
- Equipment hub at `materiel.html`, with five catalogues: sound, lighting, sound/light packs, effects/video, and structures. The 54 reference products retain the original specifications and listed TTC daily prices, with local search, type filters and price sorting.
- Per-product quote links open `nous-contacter-faq.html` with an inquiry prefilled; catalogue prices and availability are confirmed by the supplier when requesting a quote.
- Local pages for private events, professional events, the FIX-e concept, and all seven services in the Savoir Faire menu.
- Scrollable event gallery with previous/next controls and an accessible photo dialog.
- Original promotional video, compressed to 720p and served locally on demand. In a standalone HTML preview, playback streams the original site's video instead.
- Original team and social links.
- Contact form with browser validation and a review/copy dialog. Actual submission is completed on the original contact page; no email or form backend is configured here.

Contact review still links to the original contact page for actual submission; no mail backend is included. Social and review links remain external. Images, catalogue data and branding originate from Fix-Events; their source URLs are recorded in `site-data.json`. Fonts originate from the Google Fonts repository and are licensed under the SIL Open Font License (see `assets/OFL-*.txt`).
